## LeetCode Challenges Repository

This repository is dedicated to solving coding challenges from [LeetCode](https://leetcode.com/).


### Structure
- All solutions are organized in the `src/` directory.
- Each file corresponds to a specific LeetCode problem.

### Requirements
- This project uses [uv](https://github.com/astral-sh/uv) for Python dependency management and installation.

### Installation
1. Install [uv](https://github.com/astral-sh/uv#installation) if you don't have it:
	```sh
	curl -Ls https://astral.sh/uv/install.sh | sh
	```
2. Install dependencies:
	```sh
	uv sync
	```
	This will install all dependencies specified in `pyproject.toml` and `requirements.txt` (if present).

### Goals
- Practice and improve problem-solving skills.
- Write clean, efficient, and well-documented code.
- Track progress and revisit problems for better solutions.

### How to Use
1. Browse the `src/` folder for available solutions.
2. Each file is named after the problem it solves.
3. Run or modify the code as needed for your learning.
